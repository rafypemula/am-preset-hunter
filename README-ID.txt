AM LINK HUNTER MOBILE — @rafyftmca

PENTING:
Aplikasi ini bukan file HTML mandiri. Agar scanner dapat membuka halaman TikTok dan mencoba membaca komentar, dibutuhkan backend yang berjalan di server. HP kamu cukup untuk membuka dan memakai hasil deploy lewat browser.

CARA DEPLOY DARI HP (tanpa PC):
1. Ekstrak ZIP di HP.
2. Buat repository GitHub baru lewat browser/app GitHub.
3. Upload semua isi folder project ini ke repository (termasuk Dockerfile, render.yaml, app.py, requirements.txt, dan folder static).
4. Buat akun / masuk ke Render.com.
5. Pilih New > Blueprint, hubungkan repository GitHub tadi.
6. Tunggu proses build selesai. Buka URL .onrender.com yang diberikan Render.
7. Gunakan halaman itu dari Chrome Android.

CATATAN:
- Deploy gratis dapat tidur saat tidak digunakan dan perlu waktu untuk aktif kembali.
- Scanner menggunakan Playwright Chromium untuk mencoba membaca komentar yang terlihat di halaman TikTok.
- TikTok dapat meminta login, CAPTCHA, membatasi akses otomatis, atau mengubah struktur halaman. Hasil tidak dijamin lengkap.
- Aplikasi tidak meminta atau menyimpan password TikTok. Jangan pernah memasukkan password ke halaman pihak ketiga.
- Tidak ada bypass login/CAPTCHA. Jika komentar dibatasi TikTok, scanner tidak dapat mengambilnya.
- Link dan komentar yang berhasil dibaca ditampilkan agar bisa disalin.
